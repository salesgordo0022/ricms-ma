# Assistente Fiscal ICMS/MA

Consulta de benefícios fiscais do ICMS do Maranhão, CFOP/CST exatos e chatbot com IA.

- Base local com mais de 2.900 benefícios
- Resolve o CFOP EXATO + CST/CSOSN + carga tributária
- Chatbot que entende linguagem natural (Groq/llama-3.3-70b)
- Auditoria de NCM com a tabela oficial
